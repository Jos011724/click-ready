# Click&Ready · demostración Sprint 1

Prototipo frontend académico para Andes Market y la evaluación de Metodologías Ágiles. **No representa un MVP terminado ni un Sprint realmente ejecutado.**

## Demostración
Cuando GitHub Pages esté habilitado, la demostración se podrá consultar desde la URL de Pages del repositorio.

## Ejecutar localmente
Con Python 3: `python -m http.server 8000` y abrir http://localhost:8000.

## Funcionalidades implementadas
- Búsqueda y filtros para seis productos de prueba.
- Selección de tres tiendas piloto: Providencia, Ñuñoa y Maipú (sin stock real por tienda).
- Carrito en memoria: agregar, aumentar, disminuir, vaciar y total CLP.
- Formulario de ingreso con validación de interfaz, **sin autenticación real**.
- Diseño adaptable a pantallas pequeñas.

## Alcance pendiente
No hay integración con ERP, checkout sandbox, franjas horarias, envío de correos, persistencia ni backend. No se certifica Definition of Done del MVP.

## Capturas recomendadas para informe TA_4
1. Pantalla principal y selector de tienda.
2. Búsqueda y filtros.
3. Carrito con productos y total.
4. Validación de formulario.
5. Repositorio, archivos y commits en GitHub.
6. GitHub Pages, cuando esté activado.
